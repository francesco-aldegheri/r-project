# Data analysis projects in R — Francesco Aldegheri

MSc student in Applied Economics & Finance at Copenhagen Business School (BSc Economics & Management, Università di Trento).
This repository collects data analysis projects written in R during my studies.

| Project | What it does | Main tools |
|---|---|---|
| [Austria market analysis](austria-market-analysis/) | Market and industry analysis of the Austrian sweet-snacks market: demographics, labour market, demand, market concentration (C4, HHI) and firm financials | `tidyverse`, `eurostat` API, `sf`, `ggplot2`, `kableExtra` |
| [Technical changes and F1 car performance](f1-technical-changes/) | Effect of regulation changes (2020–2023) on qualifying and race performance using lap-level telemetry | `f1dataR` (FastF1), `dplyr`, `ggplot2` |

Each folder contains the R Markdown source (`.Rmd`) and the knitted report (`.html`).
To view a report, download the `.html` file and open it in a browser.
